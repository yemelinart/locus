# Границы безопасности

Locus — однопользовательское локальное приложение. Не выставляйте сервер в интернет или локальную сеть. В текущей версии нет многопользовательской авторизации.

- Сервер по умолчанию слушает `127.0.0.1`; проверяются Host, Origin и Sec-Fetch-Site. Изменяющие запросы требуют специальный заголовок. Внешний CORS отсутствует.
- Модельный и SearXNG-адреса ограничены loopback. Для них отключены proxy-переменные окружения и следование перенаправлениям.
- Reader принимает только публичные HTTP(S)-страницы на стандартных портах. Проверяется каждый результат DNS непосредственно перед соединением; адреса передаются HTTP-клиенту без повторного разрешения. Проверяются и перенаправления. Локальные, private, link-local и прочие непубличные IP запрещены.
- Размер ответа, время и частота запросов ограничены. Cookies для reader не сохраняются. robots.txt проверяется перед чтением, включая адреса после перенаправлений.
- JavaScript страниц не исполняется. Модель не получает инструментов файловой системы, командной строки или отправки сообщений.
- Внешний текст передаётся как недоверенные данные, ответ модели валидируется. Это снижает, но не устраняет риск prompt injection: злонамеренный текст всё ещё может повлиять на качество выводов или запросов. Поэтому модельный ответ не получает системных полномочий.
- Поисковая библиотека работает в отдельном короткоживущем процессе; при паузе он завершается. Это изоляция жизненного цикла, не полноценная песочница ОС. Её поисковые запросы идут на явно выбранные движки.
- Структура источников и проверка цитат предотвращают ряд выдумок, но не доказывают истинность страницы и не заменяют проверку человека.
- UI не выполняет HTML источников; внешние ссылки открываются без передачи referrer. В интерфейсе нет сторонних CDN, аналитики и удалённых шрифтов.
- Каталог данных создаётся с ограниченными правами, база — с правами 0600. Шифрование базы не реализовано; для защиты локального диска используйте штатные средства ОС.

Зависимости следует обновлять и проверять перед публичным релизом. Автообновление исполняемого кода без подписи не предусмотрено.
