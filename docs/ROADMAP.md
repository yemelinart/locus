# Последовательность развития

## 0.1 — работающий сквозной путь

Создать поиск → сохранить параметры → локальная модель планирует → бесплатный поиск → чтение HTML → извлечение с проверкой цитат → раздельные кандидаты → оценка пользователем → экспорт.

Готовность: тесты на паузу, бюджет, восстановление, запрет облачного адреса, отсутствие выдуманных цитат; браузерный сценарий создания и сохранения; отдельная короткая проверка настоящего поиска и установленной модели. Один реальный тест не доказывает качество поиска людей.

## 0.2 — интерфейс, управление и отчёты (реализовано)

English/Русский, 12 сочетаний темы, About, структурированные PDF/Markdown, анализ источников и поисковиков, действия в истории, прежние имена и гипотезы написания, обнаружение thinking-возможностей LM Studio, реальный каталог поисковых адаптеров и мини-гайды. Схема 2 сохраняет прежние исследования.

## Следующий этап — качество кандидатов и устойчивость

- Корпус 30–50 согласованных/публичных профессиональных примеров с эталонными источниками.
- Сравнение локальных моделей по планированию, схемам и ошибочным совпадениям.
- Расширение реализованного в 0.4 выбора фрагментов длинных страниц: точные позиции цитат, полнота покрытия всех упоминаний.
- Корпусная проверка смыслового контроля утверждений и комментариев, добавленного в 0.4; сравнение доли пропущенных и ошибочно принятых сведений.
- Более точное сравнение публичных ролей, организаций и периодов; измерение качества обнаружения противоречий.
- Предложение объединить карточки с явным доказательством, решение пользователя.
- Ограниченные повторы временных сетевых ошибок, счётчики всех видов попыток и более точное распределение поискового бюджета.
- Пагинация, контекстные запросы по выбранному кандидату, редактирование исходных ориентиров.

Критерий: не увеличивать число приписанных чужих фактов ради полноты. Метрики публиковать вместе с версией модели и доступностью источников.

## После 0.3 — больше доступных материалов

- PDF и OCR локально, с ссылкой на страницу документа.
- При необходимости изолированный браузер для публичных JavaScript-страниц, без обхода контроля доступа.
- Региональные адаптеры публичных профессиональных и образовательных источников.
- Кэш и актуализация источников, различение перепечатки и независимого подтверждения.
- Экспорт с более удобной навигацией, резервное копирование и перенос базы.

## Будущий выпуск для других пользователей

- Подписанная оболочка macOS с простым запуском и предсказуемым завершением процессов.
- Мастер первого запуска и проверка совместимости модели.
- Воспроизводимые сборки, проверка лицензий всех распространяемых компонентов, автоматические проверки.
- Версионируемые миграции с резервной копией, подписанные обновления и откат.
- Публичный репозиторий, документация участника и опубликованные результаты сравнительных испытаний.

Код размещён в приватном репозитории https://github.com/yemelinart/locus. Доступ выдаётся приглашённым аккаунтам. Публичный open-source запуск и подписанный установщик пока не выполнены.


## Выполнено в 0.3

Версии критериев, продолжение с новым бюджетом, объяснимая шкала по цитатам, обратимое исключение фильтрами, отметка устаревшей ручной проверки, папка исследования и ZIP с офлайн-отчётом. Статистическая калибровка вероятности, импорт архива и автоматическое обновление старых страниц остаются будущими задачами.

## Выполнено в 0.4

Анимация фактических этапов и источников, отдельная смысловая проверка утверждений локальной моделью, контроль комментариев по принятым цитатам, проверка явных противоречий, вывод об ограниченности результата, обзор по подтверждённым пользователем карточкам и перепроверка после изменения критериев. Это реализация проверочного процесса, а не доказанный уровень точности: сравнение моделей на большом корпусе остаётся следующим этапом.
