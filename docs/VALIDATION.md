# Проверка версии 0.1.0

Дата: 21 сентября 2026. Среда: macOS, Apple M1 Max, 64 ГБ памяти, Python 3.12, Node.js 22, установленный Google Chrome.

## Автоматические проверки

- 33 теста backend прошли. Проверяются очередь, пауза, отмена по времени, продолжение, сохранение после сбоя, бюджеты, проверка цитат, сетевые ограничения, настройки, экспорт и удаление.
- Ruff: ошибок нет. Производственная сборка TypeScript/Vite: успешна.
- 4 браузерных сценария прошли: сохранение и изменение исследования, настройки локальной модели, мобильная компоновка, автоматические проверки axe для главной формы и настроек.
- У мобильного интерфейса на ширине 390 px нет горизонтального переполнения. Интерфейс не загружает внешние ресурсы.
- В автоматической проверке выбранных экранов не обнаружены нарушения WCAG A/AA. Это не заменяет полного ручного аудита доступности.

Два предупреждения об устаревших интерфейсах поступают от зависимостей тестового клиента Starlette; ошибок тестов нет. Конфигурация GitHub Actions подготовлена, но удалённый CI ещё не запускался.

## Настоящий сквозной запуск

Пример: публичная профессиональная биография Guido van Rossum. Источники ограничены `gvanrossum.github.io`, начальная страница — `https://gvanrossum.github.io/bio.html`. Бюджет: 7 минут активной работы, 2 запроса, 2 страницы, 1 этап планирования.

Исполнитель: установленная локально `qwen3.8-27b-uncensored-mlx` через LM Studio на `127.0.0.1:1234`, контекст 16K, режим Qwen без длинного thinking. Бесплатный поиск — DDGS. Облачного ИИ и платного API в запуске не было.

Результат: выполнен 1 поисковый запрос, прочитаны 2 страницы, сохранены 2 отдельные карточки источников. Поиск завершился на лимите страниц. Это две карточки одного публичного автора, а не два найденных человека. Извлечённые утверждения содержат цитаты, найденные программной проверкой в прочитанном тексте. Результат сохранился после перезапуска приложения.

Первоначальная попытка через обычный chat-интерфейс потратила лимит вывода на thinking. Задание остановилось с сохранённой страницей. После добавления совместимого режима Qwen оно было продолжено. Общее учтённое время с первой попыткой — около 294 секунд, после переключения — около 156 секунд. Это наблюдение на одном запуске, не норматив скорости.

## Что ещё не доказано

Один пример подтверждает работоспособность цепочки, но не точность поиска людей, полноту источников или преимущество над конкурентами. Не проверены другие компьютеры, все семейства моделей, все языки и длительные многочасовые исследования. План сравнительных испытаний находится в [ROADMAP.md](ROADMAP.md).

## Проверка 0.2.0 — 21 сентября 2026

- 41 тест backend прошёл, включая перенос базы схемы 1 в 2 с резервной копией, точные значения reasoning, запрет неявного перехода к другим поисковикам, аудит попыток, имена и PDF на двух языках.
- 8 браузерных сценариев прошли: прежние операции, язык/тема без потери черновика, PDF, анализ и удаление из истории, динамические возможности модели и контраст 12 сочетаний темы.
- Отдельный визуальный проход по реальному приложению: все четыре раздела настроек и карточки результатов в Ocean/Dark — без найденных axe нарушений WCAG A/AA. Мобильная ширина 390 px — без горизонтального переполнения. Ошибок JavaScript не обнаружено.
- Проверены два четырёхстраничных PDF на русском и английском на сохранённом примере Guido van Rossum: кириллица читается, разделы и цитаты имеют отдельную верстку, ссылки кликабельны. Тест дополнительно проверяет буквальное отображение специальных HTML-символов.
- Прочитаны настоящие capabilities установленного LM Studio; поддержка `off/low/medium/xhigh/on` была объявлена обычной Qwen. У текущей Uncensored MLX переключатель не объявлен. Передача и отклонение reasoning проверены изолированным HTTP-тестом; это не сравнительное испытание всех уровней на всех моделях.
- Настоящий диагностический запрос о Python: DuckDuckGo и Yandex вернули по результату, Google в этом запуске не ответил успешно. Это снимок доступности, не постоянная характеристика движков. Пользовательские параметры не изменялись.
- Сохранены три существующих исследования. При установке схемы 2 создана резервная копия схемы 1. Один запущенный пользователем поиск был сохранён и продолжен после финального перезапуска; ранее приостановленное исследование не запускалось.

Полный тест длительного поиска с новой логикой на корпусе людей ещё не выполнен. Проверки интерфейса и одной цепочки не доказывают рост полноты или точности. Генерация вариантов фамилии не устанавливает её фактическую смену; пользователю предлагаются гипотезы.
